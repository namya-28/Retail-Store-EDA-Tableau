# Retail-Store-EDA-Tableau
Week 1 Tableau project – Exploratory Data Analysis of Retail Store Transactions
## Week 1 Internship Project
This project presents an exploratory data analysis of a Retail Store Transactions dataset using Tableau.

## Objective
The objective of this project was to understand the dataset, identify sales trends, compare product and store performance, investigate potential outliers, explore relationships between variables, and generate meaningful business insights.

## Dataset
The dataset contains 2,000 retail transactions with information including:
- Date
- Time
- Store ID
- Location
- Product
- Quantity
- Unit Price
- Payment Type
- Transaction ID
- Total Price

## Tools Used

- Tableau Public
- Microsoft Excel
- GitHub

## Analysis Performed

1. Sales by Product
2. Sales by Location
3. Quantity Sold by Product
4. Payment Mix
5. Year-Month Sales Trend
6. Transaction Value Outlier Analysis
7. Unit Price vs Quantity Relationship

## Key Insights

- Monitor generated the highest product sales.
- Store C generated the highest location sales.
- Printer had the highest quantity sold.
- Payment methods contributed different levels of sales.
- Monthly sales showed variation over time.
- Potentially high-value transactions were identified as outliers for further investigation.
- Unit Price and Quantity did not show a strong linear relationship.
## Dashboard
The final Tableau dashboard summarizes the major findings using interactive visualizations.
## Project Outcome
This project demonstrates the practical use of Tableau for exploratory data analysis, visualization, trend analysis, outlier investigation, relationship analysis, and business insight generation.
